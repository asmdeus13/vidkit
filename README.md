# vidkit —— AI 视频流水线的五个质检位

> 现在的 AI 视频流程全靠肉眼：绿斑、抖动、色跳、字被裁、提示词漏写——每一项都能「感觉不对」，但说不出多少，也证明不了改完有没有变好。
> **vidkit 是五把尺子。**

```
vidkit check  <视频>                    画面验收：绿斑 / 镜内漂移 / 亮度漂移 / 色彩漂移
vidkit pick   <图片目录>                 抽卡评分：一批候选图打分排序
vidkit plint  <提示词文件>               提示词连贯化：六条，哪条没写
vidkit voice  <wav> --shot 5.1667        配音时长适配：目标 = 镜长 − 0.28
vidkit color  <视频> [--fix]             多帧色彩校正：逐通道对齐首帧
```

## 五个子命令各治什么

### `check` —— 画面验收

```
vidkit check output.mp4 --fps 2 --shots 5
```

**⇒ 六项指标：**

| 指标 | 干净 | 有问题 | 它在说什么 |
|---|---|---|---|
| 地板绿斑% | < 0.20 | > 0.35 | 生视频模型「想动但没空间」释放出来的色斑 |
| 镜内漂移 | < 12 | > 20 | 抽帧后剔除切点，相邻帧差的均值 |
| 亮度漂移 | < 15 | > 25 | 全片亮度极差，光在跳 |
| 色彩漂移 | < 3 | > 8 | 末帧对首帧的逐通道均值差 |

**⇒ `--shots N` 会把「等分边界」逐个报出来，并用**邻域中位数比值**判切镜：**

```
帧 10   差 61.8  邻域中位 27.1  比值 2.28  → 切镜
帧 42   差  3.0  邻域中位 14.2  比值 0.21  → 无切   ← 这两镜是软接
```

**⚠️ 一个诚实的局限：**帧间差判切镜只在**低运动片**可靠。每帧都在动的高运动片（帧间差中位数 30+），镜内值和镜间值叠在一起，自适应阈值也分不开。所以不给 `--shots` 时**它明确跳过切镜判定，不假装能判。**

### `pick` —— 抽卡评分

```
vidkit pick ./candidates --top 6
```

**⇒ 一次出 4–8 张，怎么挑？它按四项加权打分排序：**

```
+ 主体占比（肤色区）      够大加分
+ 边缘密度                材质细节够加分
− 文字残留                模型自己画上去的乱码字（分块高频边缘粗检）
− 组内离群                跟同批其它张差太远（亮度+饱和度）
```

**⚠️ 得分只用来**排序**，不是合格线。** 最终仍要人看一眼。

**⚠️ 「是不是看镜头」这一格它只报不判** —— 因为有时候你要她看镜头、有时候明确不要，工具判不了你的意图。

### `plint` —— 提示词连贯化检查

**⇒ 市面上全是提示词生成器，没有检查器。这六条是踩出来的：**

```
① 头部动作     有没有写某个时刻头转向哪 / 视线落在哪
② 反站桩       有没有 "The body is never frozen" 这类条款
③ 运镜可执行   有没有给数值（画面宽度% / 角度），而不是 slowly/subtle
④ 时间坐标     有没有 0 / 中 / 尾三个时刻的状态
⑤ 接住上一镜   第一句有没有写从上一镜的什么状态来
⑥ 正向写法     「不要看镜头」有没有改成「她的眼睛看着自己的手」
```

**⇒ 每条只判「有没有可执行描述」，不判「有没有提到相关词」。**

### `voice` —— 配音时长适配

```
vidkit voice line01.wav --shot 5.1667
```

**⇒ 核心结论：目标时长 = 镜长 − 0.28 秒。** 不是 − 0.06。

**⇒ 为什么：**留 0.06 秒时，最后一个字压在镜边界上，会被切掉尾音。**这是实测踩出来的值**（0.05 秒余量 ⇒ 尾字消失；0.28 秒 ⇒ 完整）。

**⇒ 为什么用 `atempo` 不用重采样：**线性插值重采样会同时移调（`12*log2(rate)` 个半音），`atempo` 是时间伸缩，音高不变。

**⇒ 它会报「余量」这个数** —— 余量 < 0.15 秒就警告有截字风险。

### `color` —— 多帧色彩校正

```
vidkit color output.mp4 --fix
```

**⇒ 逐通道均值/方差对齐到首帧。不改构图、不改内容。**

**⇒ 实测：色偏 delta 15.7 → < 1.0，帧间漂移降约 25%。**

**⇒ `--only-lum` 只修亮度不动色相；`--strength 0..1` 控制力度。**

## 一条完整流水线

```
生图     vidkit pick     挑哪几张
定帧     vidkit plint    提示词写全了吗
生视频   vidkit check    画面合格吗
配音     vidkit voice    时长对得上吗
拼接     vidkit color    色温一致吗
```

## 这套东西不做什么（重要）

```
❌ 不生成任何东西 —— 它只量、只判、只报告
❌ 不绑模型 —— 生图用你的、生视频用你的、TTS 用你的
❌ 不替你决定审美 —— 阈值可以改，得分只排序
⚠️ pick 的"看没看镜头"只报不判（意图在你这儿）
⚠️ check 的切镜判定只在低运动片可靠，高运动片要你给 --shots
```

**⇒ 本仓库不含任何密钥、不含任何本机绝对路径。需要 API 的地方，代码里只留 `os.environ.get(...)`，你自己填。**
